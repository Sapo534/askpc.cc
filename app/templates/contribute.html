Participate in Development

askpc.cc is open source, licensed under AGPL-3.0. Help is welcome, and you don't have to write code to give it.

Ways to help

  • Improve content: fix mistakes in Knowledge Base articles and Wiki terms, or suggest new ones.
  • Report bugs: open an issue with steps to reproduce, your browser and device.
  • Suggest features: open an issue before starting large changes, so we can agree on the idea first.
  • Write code: the backend is FastAPI + PostgreSQL, the frontend is plain HTML/CSS with minimal JS.

Source code

The repository lives at Sapo534/askpc.cc. It has a README with local setup instructions (Docker).

Sending a pull request

  • Fork the repository and create a branch from main.
  • Keep changes focused: one topic per pull request.
  • Describe what changed and why.

License of contributions

By submitting a contribution you agree that it is licensed under AGPL-3.0, the same as the rest of the project.
